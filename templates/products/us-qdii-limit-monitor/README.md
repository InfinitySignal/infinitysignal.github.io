# 美股QDII限额实时监控模板

`monitor.html` 仅作为仓库内的 HTML 模板。`templates/` 不属于 Astro 的公开资源目录或页面目录，因此不会发布到官网，也不会出现在产品的 HTML 文件列表中。

自动生成流程可读取此模板，填入以下区域：

- `#updated-at`：更新日期时间。
- `#latest-changes`：最新变更表的表格行，包含未来生效的变更，日期填写公告生效日期。有限额转暂停显示“暂停申购”；暂停转开放显示“开放申购，直销 x 元，代销 x 元”；金额变更按渠道显示“直销从 x 元提升至 x 元，代销从 x 元下降至 x 元”。
- `#monitor-rows`：完整监控表的表格行，仅展示更新当日已生效的情况，未来变更生效前保留原状态及对应生效日期。限额列简写为“直销 x 元，代销暂停申购”等格式，不展示变更过程或长篇说明。

两个表格中的所有金额（含变更前后的金额）均使用 `<span class="money-amount">100 元</span>` 标红。渠道之间可使用 `<br />` 换行。模板内的基金、代码、金额和日期均为虚构样例，基准日为 2026-10-15；未来暂停的样例在全量表中仍显示当日状态。

填入真实数据后移除 `#sample-note`。需要发布时，将生成的 HTML 写入 `public/products/us-qdii-limit-monitor/items/`，并重新构建、部署网站。
