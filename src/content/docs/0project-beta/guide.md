# Project Beta Guide

Project Beta is an experimental module for anomaly detection in unstructured signal data.

## Overview

Beta uses machine learning models trained on historical datasets to identify outliers and patterns that deviate from the norm.

## Usage

1. Prepare your dataset in CSV format.
2. Upload it via the Beta dashboard.
3. Run the detection pipeline.
4. Review the generated report.
